# Carpeta Public

Esta carpeta contiene archivos estáticos que se sirven desde la raíz de la aplicación.

## Guía de Postventa

Para que el botón de descarga funcione correctamente, coloca el archivo PDF de la guía de postventa aquí con el nombre:

**`guia-postventa.pdf`**

El archivo debe estar en esta ubicación:
```
public/guia-postventa.pdf
```

Una vez que coloques el archivo, el botón de descarga en el Portal funcionará automáticamente.
